# Even Pay — legal

The privacy policy and data-deletion instructions for the Even Pay Android app
(`com.simpletoolslabs.evenpay`), served by GitHub Pages.

This repository is public because Google Play requires both URLs to be publicly
reachable without a login. The app's source is private and lives elsewhere.

The source of truth for `index.html` is `legal/index.html` in the app
repository. Edit it there and copy it here, so the published page and the app
it describes are versioned together.
